# Project Quasar 개인정보 처리방침

시행일: 2026년 11월 16일

TEAM.ER(이하 "운영자")는 게임 Project Quasar(가칭, 이하 "게임")를 이용하는 분의 개인정보를 「개인정보 보호법」 등 관련 법령에 따라 처리합니다. 이 방침은 게임이 어떤 정보를 왜 처리하고, 이용자가 어떻게 권리를 행사할 수 있는지 알려 드립니다.

게임은 스텔라이브의 비공식 팬게임이며, 스텔라이브 및 소속 회사와 관련이 없습니다.

## 1. 처리하는 개인정보와 목적

게임은 회원가입을 받지 않습니다. 처음에는 게스트로 시작할 수 있고, 원하는 경우 Google, 네이버 계정 중 하나로 로그인해 여러 기기에서 진행을 이어 할 수 있습니다. 게스트는 서버에 로그인하지 않으며, 플레이어 ID나 진행 데이터를 운영자나 Unity Gaming Services로 보내지 않습니다.

| 언제 | 처리하는 항목 | 목적 |
| --- | --- | --- |
| Google 또는 네이버 계정으로 로그인하거나 연결할 때 | Unity Gaming Services가 발급하는 플레이어 ID, 로그인 유지용 인증 정보 | 로그인 유지, 계정 보호 |
| Google 계정을 연결하거나 Google로 로그인할 때 | Google 계정 고유 식별자 | 같은 플레이어를 여러 기기에서 찾기 |
| 네이버 계정을 연결하거나 네이버로 로그인할 때 | 네이버 회원 고유 식별자(이 게임에서만 쓰이는 값) | 같은 플레이어를 여러 기기에서 찾기 |
| 계정을 연결한 뒤 동기화할 때 | 게임 진행 데이터, 저장 시각, 저장 요약, 기기 종류(예: "Windows PC", "Android · 기종명"), 설치할 때마다 무작위로 만드는 기기 구분 번호 | 기기 사이 진행 동기화, 저장이 엇갈렸을 때 고를 수 있게 보여 주기 |
| 게임이 서버와 통신할 때(자동 생성) | 접속 IP 주소, 접속 일시, 기기·운영체제 정보 | 서비스 제공과 보안 |

- 게임은 Google, 네이버에서 **이메일, 이름, 닉네임, 프로필 사진, 전화번호를 받지 않습니다.** 로그인 과정에서 각 회사가 발급하는 토큰에 이런 정보가 들어 있더라도, 게임은 이를 읽거나 저장하거나 쓰지 않습니다.
- 네이버 로그인은 운영자가 관리하는 서버(Cloudflare Workers)가 중계합니다. 이 서버는 네이버가 발급한 접근 토큰으로 회원 고유 식별자만 확인하고, 토큰과 나머지 응답은 저장하지 않습니다. 로그인 처리를 위한 임시 기록은 완료 즉시 지우고, 완료되지 않은 기록도 늦어도 10분 안에 지웁니다.
- 게스트의 진행은 **이용자 기기에만** 저장하고 운영자 쪽(클라우드)으로 보내지 않습니다. 계정을 연결하는 순간부터 클라우드에 저장합니다. 게스트 상태로 게임을 지우거나 기기를 바꾸면 진행을 되살릴 수 없습니다.
- 게임은 비밀번호, 실명, 전화번호, 위치 정보를 받지 않습니다.
- 게임은 광고, 이용 분석, 충돌 보고 기능을 쓰지 않습니다.

## 2. 보유 기간

- 계정 정보와 클라우드 저장: 이용자가 탈퇴(삭제)를 요청하거나 서비스를 종료할 때까지 보유합니다. 삭제를 요청하면 지체 없이(늦어도 30일 이내) 파기합니다.
- 로그아웃: 이 기기의 로그인 기록만 지웁니다. 계정과 클라우드 저장은 탈퇴하거나 삭제를 요청할 때까지 보유합니다.
- 네이버 로그인 중계 기록: 로그인 완료 즉시 파기하고, 완료되지 않은 기록도 늦어도 10분 안에 파기합니다.
- 접속 기록: 운영자는 서버가 받은 요청의 기록을 따로 저장하지 않습니다. Unity와 Cloudflare가 서비스 운영과 보안을 위해 남기는 기록은 각 회사의 방침을 따릅니다.
- 기기에만 있는 저장: 이용자 기기에 있으며, 게임을 삭제하거나 앱 데이터를 지우면 함께 지워집니다.
- 서비스를 종료하면 보유한 정보를 지체 없이 파기합니다.

## 3. 파기 방법

전자 파일 형태의 정보는 다시 살릴 수 없는 방법으로 삭제합니다. 종이 문서로 보관하는 개인정보는 없습니다.

## 4. 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 법령에 특별한 규정이 있는 경우는 예외입니다.

## 6. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다.

- 게임 안에서: 설정에서 로그아웃과 탈퇴(계정 삭제)를 할 수 있습니다. 탈퇴하면 계정, 클라우드 저장, 이 기기의 저장을 함께 삭제하며 되돌릴 수 없습니다. 게임을 삭제하면 기기에 있는 저장이 지워집니다.
- 각 회사에서: Google 계정 설정의 연결된 앱 관리, 네이버 내정보의 연결된 서비스 관리에서 게임과의 연결을 끊을 수 있습니다. 게임에서 탈퇴해도 각 회사의 연결 목록에서는 게임이 자동으로 지워지지 않으니, 필요하면 여기서 끊어 주세요.
- 이메일로: 아래 7항의 이메일로 요청합니다. 게임 설정 화면의 **플레이어 ID**(복사 버튼)를 함께 보내 주시면 빠르게 확인할 수 있습니다.
- 운영자는 요청한 사람이 해당 플레이어인지 확인한 뒤 10일 이내에 처리 결과를 알려 드립니다.

## 8. 만 14세 미만 아동

게임은 만 14세 미만 아동을 이용 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 알면서 수집하지 않습니다. 만 14세 미만 아동의 정보가 처리된 사실을 알게 되면 지체 없이 삭제합니다.

## 9. 안전성 확보 조치

- 게임과 Unity, Cloudflare, Google, 네이버 사이의 통신은 암호화(HTTPS)합니다.
- 게임은 비밀번호를 받지 않고, 로그인 확인은 각 로그인 제공자와 Unity가 합니다.
- 클라우드 저장 서버는 요청마다 Unity가 서명한 로그인 토큰을 검증해, 본인의 저장만 읽고 쓸 수 있게 합니다.
- 로그인 중계에 쓰는 비밀키는 게임 프로그램에 넣지 않고 서버의 비밀 저장소에만 둡니다.
- 클라우드 저장과 서버를 관리할 권한은 운영자에게만 두고, 관리 계정에는 2단계 인증을 씁니다.

## 10. 자동 수집 장치(쿠키)

게임은 쿠키를 쓰지 않습니다. 다만 네이버 로그인을 진행하는 동안, 로그인 중계 서버(Cloudflare Workers)가 이용자의 브라우저에 로그인 확인용 쿠키 하나를 최대 10분 동안 둡니다. 이 쿠키에는 이번 로그인 요청을 확인하는 무작위 값과 만료 시각만 들어 있고 개인정보는 들어 있지 않으며, 로그인을 마치면 지웁니다. 로그인할 때 열리는 Google, 네이버 로그인 페이지의 쿠키는 각 회사의 정책을 따릅니다.

## 11. 방침의 변경

이 방침을 바꾸면 이 페이지에 바뀐 내용과 시행일을 알립니다.

- 2026년 11월 16일: 네이버 로그인 추가, 클라우드 저장을 Cloudflare로 이전(5항 위탁·국외 이전 표 변경), 네이버 로그인 중계 처리 추가, 로그아웃과 탈퇴 안내 추가, 쿠키 안내 추가
